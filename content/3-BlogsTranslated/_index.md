###  [Blog 1 - DISA STIG for Amazon Linux 2023 is now available](3.1-Blog1/)
The DISA STIG for Amazon Linux 2023 (AL2023) has been released by AWS and the Defense Information Systems Agency (DISA), providing detailed security-hardening configurations. AWS Systems Manager (SSM) and EC2 Image Builder offer native solutions to simplify the deployment of AL2023 DISA STIG configurations for both new and existing EC2 instances. This STIG release demonstrates Amazon Linux's ongoing commitment to providing government-validated security tools and configurations for highly regulated environments.

###  [Blog 2 - Overview of security services available in AWS Dedicated Local Zones](3.2-Blog2/)
The article provides an overview of AWS security services operating within AWS Dedicated Local Zones (DLZs) to help organizations meet stringent digital sovereignty and compliance requirements. These services allow data to remain on-premises in DLZs while still leveraging powerful security features from the Parent Region.

Key security components include the AWS Nitro System, which provides technical isolation, and the AWS KMS External Key Store, which gives customers complete control over their encryption keys. Amazon Inspector and Amazon GuardDuty perform continuous vulnerability scanning and threat detection without requiring data to move out of the DLZs. AWS Certificate Manager (ACM) and AWS Shield ensure secure TLS certificate management and protection against DDoS attacks at the AWS edge. AWS CloudTrail maintains comprehensive governance and auditing by storing logs in the Region while the data remains in the DLZs.

Through this integration, Dedicated Local Zones present a robust solution for running mission-critical workloads that require security compliance and low latency.
